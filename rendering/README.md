# Rendering Systems

Pasta para implementações, exemplos e presets de pipelines de render utilizados pelo LookSpace.

Estrutura proposta:
- `rendering/pipelines/` — definições de passes e presets.
- `rendering/passes/` — HLSL/GLSL snippets e configurações.
# Rendering

The `rendering/` domain houses shared rendering architecture, shader references, and cinematic pipeline documentation.

## Responsibilities

- Render architecture and shared visuals
- Pipeline blueprints for cinematic rendering
- Integration guides for UE5 and runtime rendering systems

## Key Goals

- Provide a unified rendering standard across the project
- Document cinematic rendering workflows and performance strategies
- Keep visuals consistent with LookSpace quality targets
