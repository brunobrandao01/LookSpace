# Server

The `server/` domain is responsible for backend services, Supabase integration, and platform APIs.

## Responsibilities

- Authentication and authorization
- Persisting mission state and user data
- Hosting serverless endpoints and data functions
- Managing telemetry and analytics events

## Key goals

- Define the Supabase schema and data contracts
- Establish API patterns for realtime sync and event delivery
- Build a secure deployment workflow for server services
