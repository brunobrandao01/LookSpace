# Spaceships

The `spaceships/` domain contains prototype architecture and engineering systems for LookSpace spacecraft.

## Responsibilities

- Spaceship prototype planning and system design.
- Integration with cockpit visuals, navigation, and mission systems.
- Reusable architecture for future spacecraft classes.

## Key Goals

- Build a scalable spacecraft system foundation
- Support aerospace simulation and cinematic control
- Keep ship systems modular and production-ready
