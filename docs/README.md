# Docs

The `docs/` folder contains the authoritative studio documentation for LookSpace.

## Contents

- `ARCHITECTURE.md` — system architecture, domain boundaries, and deployment strategy
- `ROADMAP.md` — phased development plan and studio-level milestones
- `PROJECT_OVERVIEW.md` — project vision and operational guidelines
- `PIPELINE.md` — development and production workflow
- `GIT_AUTOSYNC.md` — GitHub sync documentation and safe automation
- `UNIVERSE_ENGINE.md` — universe engine design and simulation strategy
- `PROCEDURAL_GENERATION.md` — procedural generation systems and workflows
- `RENDERING_ENGINE.md` — rendering architecture and visual systems
- `SPACESHIP_SYSTEMS.md` — spaceship engineering and mission subsystems
- `MULTIPLAYER_ARCHITECTURE.md` — multiplayer design and session architecture
- `AI_SYSTEMS.md` — AI orchestration and content generation systems
- `CINEMATIC_RENDERING.md` — cinematic pipeline and camera-driven visuals

## How to use this folder

Use these docs to:

- align engineering, design, and art teams
- record architectural decisions and technical standards
- support onboarding for new contributors
- preserve production-grade workflows and studio culture
