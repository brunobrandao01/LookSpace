# Project Overview

LookSpace is built to be a premium cinematic space simulation platform with a strong production foundation.

## Mission

Create a visually striking, scientifically inspired universe experience that feels like a next-generation space film and interactive platform.

## Studio Goals

- Build with AAA-level organization and pipeline discipline
- Scale from prototype to live platform using managed cloud services
- Maintain a clean separation between art, simulation, backend, and AI systems
- Use a modern, professional repository structure for long-term maintainability

## Delivery Principles

- **Modular architecture**: Each domain owns a bounded responsibility
- **Cloud-native platform**: Supabase and Vercel are core deployment targets
- **Unreal-first visuals**: UE5 drives the cinematic presentation
- **TypeScript tooling**: Shared developer experience across web and backend domains
- **Document-first development**: Use `docs/` to capture major decisions and strategy
