# Spaceship Visual Concepts

Objetivo: estruturar conceitos visuais e linguagens de design para as naves protótipo.

- Principais pontos:
  - Silhueta reconhecível a distância; contraste entre casco e detalhes iluminados.
  - Modularidade: componentes intercambiáveis (cockpit, motores, armas, painéis solares).
  - Materialidade: casco metálico com micro-scratches, emissive thrusters, procedural grime.

- Entregáveis:
  - 3 variantes de silhouette (Scout, Explorer, Capital)
  - Sheet de materiais e palette de emissive/flare
