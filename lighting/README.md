# Lighting

The `lighting/` domain contains cinematic lighting workflows and production practices.

## Responsibilities

- Cinematic illumination strategies for space, planets, and interiors.
- Light rig configuration for dynamic scenes and cinematic sequences.
- Atmosphere, star, and planetary lighting integration.

## Key Goals

- Establish a AAA lighting pipeline for Unreal Engine 5
- Support realistic environmental and cinematic lighting systems
- Keep lighting practices modular and scalable across the project
