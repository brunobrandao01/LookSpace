# Prototype Scenes

Organização para cenas de protótipo e sequencers.

Use esta pasta para:
- `SCENE_001` — primeira cena cinematográfica Earth-in-space.
- `SCENE_001_MasterSequence` — sequência mestre.
- `CameraMarkers` — referências de câmeras e rigs.

Estes arquivos são gerados dentro do Unreal Editor quando o projeto estiver configurado.
