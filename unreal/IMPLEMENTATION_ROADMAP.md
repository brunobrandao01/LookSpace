# Implementation Roadmap — Fases

1) Prototype Phase (1–2 weeks)
- Scaffold UE5 project, import low-res assets, implement one cinematic level with placeholder ship.

2) First Playable Scene (3–6 weeks)
- Polish transitions, add volumetric clouds, basic ship controls, and Sequencer-driven shots.

3) Visual Polish (ongoing)
- Iterate on atmosphere scattering, clouds, ocean, ship materials, and FX.

4) Performance Optimization (parallel)
- Integrate Nanite/Lumen tuning, LODs, virtual texturing, and platform-specific settings.

5) Next-Gen Roadmap
- Research path-traced elements, hybrid ray-tracing for reflections, advanced denoising on Movie Render.
