# Unreal

The `unreal/` domain contains Unreal Engine 5 workspace structure, integration guidance, and UE-specific best practices.

## Responsibilities

- Unreal project setup and workspace organization.
- Engine integration guidance for assets, shaders, and cinematic systems.
- Documentation for Unreal-specific deployment and tooling.

## Key Goals

- Keep Unreal project architecture scalable and production-ready
- Support UE5 best practices for large-scale cinematic projects
- Provide clear workflow documentation for artists and engineers
