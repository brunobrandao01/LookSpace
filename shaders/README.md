# Shaders

The `shaders/` domain houses shared shader architecture, material utilities, and rendering effect definitions.

## Responsibilities

- Maintain reusable shader patterns for UE5 and rendering subsystems
- Provide procedural material definitions for planets, atmospheres, and space visuals
- Document shader conventions for cinematic and scalable look development

## Key Goals

- Support high-performance cinematic visuals
- Keep shader code modular and maintainable
- Enable consistent visuals across runtime and production pipelines
