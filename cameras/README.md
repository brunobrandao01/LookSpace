# Cameras

The `cameras/` domain contains immersive camera architecture and cinematic rig planning.

## Responsibilities

- Camera systems for exploration, cockpit, and cinematic sequences.
- Immersive viewpoint management and shot orchestration.
- Integration with rendering, lighting, and movement systems.

## Key Goals

- Define camera rig architecture for AAA cinematics
- Support immersive and narrative-driven camera flows
- Provide a structured camera development foundation for UE5
