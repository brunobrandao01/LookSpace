# Website

The `website/` domain contains the public-facing Vercel site and documentation portal.

## Responsibilities

- Marketing and product showcase
- Developer and production documentation
- Community and launch communications
- Deployment-ready web presence

## Key goals

- Bootstrap a Vercel-ready front-end project
- Create a polished landing page for the LookSpace universe
- Publish architecture and roadmap documentation for stakeholders

## Local development

```bash
cd website
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deployment

This project is Vercel-ready. The `vercel.json` file is included to configure the Next.js build.

## Tech stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion
