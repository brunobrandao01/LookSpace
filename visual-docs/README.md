# Visual Docs

The `visual-docs/` domain contains presentations, references, and visual system documentation for LookSpace.

## Responsibilities

- Store art direction documentation and visual references.
- Maintain pipeline diagrams and rendering system charts.
- Organize visual research artifacts and style guides.

## Key Goals

- Provide a central location for AAA visual documentation
- Keep visual system references aligned with production standards
- Support artists and technical artists with clear design documents
