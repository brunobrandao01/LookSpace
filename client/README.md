# Client

The `client/` domain houses the Unreal Engine 5 runtime and interactive experience.

## Responsibilities

- Cinematic scene assembly
- Real-time simulation rendering
- UI/UX integration for exploration
- Visual asset ingestion and runtime optimization

## Key goals

- Build a production UE5 project skeleton
- Define scene and level folder conventions
- Establish lighting, post-processing, and camera pipeline standards
- Integrate runtime hooks for backend sync and mission systems
